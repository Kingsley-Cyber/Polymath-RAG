# Product Slots (product_slots)
From corrected LivedSituations: name ProductSlots (physical job + moment +
scope), then slot candidates with: id, name, quality (0..1 from evidence
support), physical_jobs[], moments[], collection_roles (INSIDER_GEM/UTILITY/
DISCOVERY/COMPLEMENT/IDENTITY), mechanism_family, why_this (traceable lived
reason — "because runners use it" is an automatic genericness hit).
Every slot must answer: why THIS product, THIS moment, THIS physical job, NOW.
