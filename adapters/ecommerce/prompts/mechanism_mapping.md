# Mechanism Mapping (mechanism)
Only reached when evidence is sufficient. From SUPPORTED/WORKING hypotheses + observations,
name concrete product MECHANISMS (schema mechanism.json): the physical principle that removes
the validated friction (e.g. wearable-wireless-audio), supporting_observation_ids (real ids
from observations[]), status SUPPORTED only when those observations genuinely back it,
else PROPOSED. Add product_candidates[]: known existing products embodying each mechanism
(validation that the mechanism ships today). Check registry mechanisms.csv for prior art first.
