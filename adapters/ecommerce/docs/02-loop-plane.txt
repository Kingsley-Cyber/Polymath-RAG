The important point is that we should not replace the graph control plane with loops. The two should nest:

Control Graph = the authored structure of one opportunity investigation.
Loop Specification = the external pilot that keeps giving that graph/Hermes another turn until verification says the goal is satisfied, disproven, blocked, stalled, or exhausted.

The prompt-graph source requires the graph to exist explicitly, independently of its prompts, with executable semantics and artifact/version status. The loop source separately defines an external reusable artifact containing a trigger, goal, execution, verification, stopping rule, and persistent memory.

That combination is exactly what you want if the criterion is:

I start Hermes, walk away, and when I return it has either completed the intended investigation correctly or stopped for an explicit defensible reason—not wandered, self-approved, or silently given up.

Then add an independent hypothesis checker

This is where the loop research adds something very important.

There are parts of hypothesis evaluation that cannot be deterministic.

Python can establish:

The bridge followed the rules.

Python cannot establish:

This is a genuinely plausible and nontrivial explanation of the source evidence.

That is semantic judgment.

So use:

θ generator
      ↓
Python L1/L2 verification
      ↓
fresh skeptical evaluator
      ↓
Python records verdict

"I generated a good hypothesis."

"I reviewed myself and agree."

The loop literature specifically identifies this self-grading pattern as the "nodding loop" and recommends structural generator/evaluator separation.

For the semantic bridge evaluator, use a fresh context and, ideally, a separate model/subagent.

Its instruction should be adversarial:

Assume this bridge is unsupported until demonstrated otherwise.

Do not generate a better opportunity.

Evaluate only:

1. Does each semantic step follow plausibly?
2. Is any step merely associative rather than explanatory?
3. Are there missing intermediate mechanisms?
4. Is the proposed product mechanism premature?
5. Are credible alternative explanations missing?
6. What observation would falsify the bridge?

Return PASS / REVISE / REJECT with reasons.
