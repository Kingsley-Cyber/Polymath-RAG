# Lived Situation (lived_r1 / lived_r2)
Build LivedSituations, not personas: scope + experience level + activity +
MOMENT (before/arrival/during/transition/after) + environment + participants +
body/hand state + object state + constraints + inferred frictions. Authority:
SIMULATED_HYPOTHESIS in R1; in R2 you must correct against field evidence —
keep what survived, revise what the community contradicted, and capture
PREFERENCE CLUSTERS instead of averaging disagreements. A loadout is built
from several LivedSituations, never from one description of the niche.
Journey rule: generic ecommerce lives in DURING; insider collections mine
BEFORE, TRANSITIONS, and AFTER.
