# ADR-0017 — LLM-direct extraction is the canon

- **Status:** accepted 2026-09-03 (owner directive; supersedes the span-tagger contracts of ADR-0005 / ADR-0011 / ADR-0015 wherever they conflict)
- **Context:** the pipeline was refactored from GLiNER + spaCy span tagging to LLM-direct extraction (`llm-direct-v1`), but the tagger's rules kept enforcing: anchor-chunk endpoint attestation rejected 46 % of proposed relations, types were flattened to Concept for the graph, replay and retrieval validation graded the interpreter view and fact-tuple self-consistency, the settings default and the operating rules still named the old path.
- **Decision:** `llm_live` is the default and only canonical extraction provider. The LLM gate (`llm_extraction/gate.py`) is the sole authority. A fact is durable knowledge iff its quote is attested verbatim; endpoint attestation is a recorded level (quote › anchor › neighborhood › document › abstract-with-token-support), not a veto. Junk-surface, unattested-quote and interrogative rejections remain. The open vocabulary (`raw_types`, `predicate_raw`) is projected and displayed; core types and the predicate enum stay the index vocabulary. Replay is graded from stored raw LLM responses; retrieval is graded on gold questions. The span-tagger path stays selectable for forensics and is never enforced by a gate, fence or test.
- **Consequences:** plan `docs/wiki/plans/LLM-DIRECT-CANON-PLAN.md` (phases P0–P6). Re-extraction of existing corpora is an owner decision (P6). Historical tests are skip-marked with this ADR as the reason. The EXACT_REPLAY release gate changes contract (raw-response ledger); the GRAPH gate is re-expressed against holdout accuracy.
- **Deletion (2026-09-03, owner: "delete the retired code"):** the tagger path is removed from the tree — GLiNER/spaCy sidecars, the rule-pack package, the candidate/syntax/rescue/admission workers, their settings, contract keys and the S3 syntax claim gate (work-log 2026-09-03-llm-direct-canon item 12). `bundle_integrity` pins `llm_extraction/gate.py` + `workers/llm_direct.py` as the semantic authorities (lock `v5-production-002-llm-direct`) and its census requires a production caller of the gate. Rollback of the deletion is `git revert`, not a provider switch: no `gliner` branch exists any more.
