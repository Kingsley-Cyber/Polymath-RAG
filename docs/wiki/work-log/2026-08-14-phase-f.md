# Phase F: disposable projections, destructive-reconstruction gate, ADR-0007, experiment 0002

## Contract

Admit Phase F exactly as scoped: Postgres remains the only authority;
Qdrant and Neo4j become disposable projections with their own durable
stages (project_qdrant, project_neo4j, verify_projections), each
satisfying: same source artifact + same projection contract = same
projection id. No projection may invent a semantic identity.

Also admit: ADR-0007 (lexical evidence lane replaces the neural
evidence pass) and experiment 0002 (layer-wise recovery measurement
with a frozen gold set).

## Changes

- `shared/polymath_shared/projection_contracts.py`: projection/receipt
  identity (content hash of projection|kind|source|contract), the
  deterministic hash-embed-v1 embedding contract (512-dim, zero model —
  the neural embedder lands in Phase G as a new contract id), and
  deterministic uuid5 point ids (Qdrant 1.13 accepts UUIDs only; the
  source chunk_id stays in the payload).
- `workers/project_qdrant_worker.py`: children+parents → collection
  `polymath_<corpus_hash>_<embedding_contract>`; Postgres receipt
  commits in the stage transaction AFTER the store write (receipts are
  the commit point; a crash between them leaves a detectable orphan).
- `workers/project_neo4j_worker.py`: entities/facts/evidence → MERGE
  under uniqueness constraints (stores/neo4j/constraints/
  0001_uniqueness.cypher); one REL edge per fact id (docx §18).
- `workers/verify_worker.py`: reconciles receipts vs live stores —
  store loss clears receipts (census re-drives), orphans are deleted
  from the store, orphan receipts deleted, and the run degrades (never
  silently passes) until convergence.
- `control/census.py`: five-stage chain (intake → extract →
  project_qdrant → project_neo4j → verify_projections) with per-stage
  event types; projection receipt gaps re-arm projector stages even
  when the stage attempt is ok.
- ADR-0007 documents the architecture change; experiment 0002 ships
  `eval/gold/relations_v1.yaml` (frozen) + `eval/measure_layers.py`
  (read-only harness) with recorded numbers.
- Rule pack v1.0.1: CAUSES accepts Product effects; STATED_IN accepts
  Document subjects (both from experiment 0002).
- Deployment: Makefile targets + launchd units for the three new
  workers; Neo4j moved to 7475/7688 (host 7474 is the user's existing
  v3.3 graph — never touched).

## Proof

- Acceptance gate: all 7 destructive-reconstruction tests pass against
  live stores (`POLYMATH_INTEGRATION=1 pytest tests/integration`):
  collection delete → exact reconstruction; Neo4j wipe → exact
  reconstruction; mid-write crash → converges with no duplicates;
  replay → zero new facts and zero duplicate points; contract bump →
  new collection version, source facts unchanged; injected missing
  point + missing edge → census detects exactly two discrepancies;
  injected orphan → verifier deletes it, never silently accepts.
- Live autonomous run: intake POST → all five stages → query_ready in
  ~60s with no manual steps; receipts observed across qdrant (18) and
  neo4j (67).
- Experiment 0002 recorded: compiler 95.7% predicate / 100% direction /
  100% abstention on gold inputs; E2E 66.7% P / 60.0% R / 63.2% F1 /
  0% duplicates, with per-layer attribution (typing 81%, triggers
  76.7%/60.5%, candidates 74.1%).
- 26 unit tests + 7 integration tests + all three guards green.

## Rejected claims

- No retrieval logic in Phase F (as scoped): projections only.
- No neural embedder yet: hash-embed-v1 is an explicit, versioned,
  deterministic contract for exercising the projection layer; the
  semantic embedder is a Phase G contract addition, not a silent swap.
- The existing Neo4j on port 7474 belongs to v3.3 and was left alone.

## Open contract gaps

- Phase G: neural embedder sidecar + retrieval primitives (G1–G5).
- L3 trigger precision (60.5%) and L2 passive coverage (spaCy optional)
  are recorded work from experiment 0002, not yet admitted.
- `POLYMATH_REQUIRE_PINNED=1` still pending the Phase C weights digest.
