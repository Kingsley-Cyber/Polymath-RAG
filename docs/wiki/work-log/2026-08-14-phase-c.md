# Phase C: GLiNER qualification + first end-to-end ingestion proof

## Contract

Measure the GLiNER runtime on the deployment Mac, decide the evidence-pass
strategy from measurements, and prove the full ingestion path end-to-end:
intake -> chunk -> entity pass -> evidence proposal -> compiler -> facts ->
receipts -> census -> query_ready.

## Changes

- Qualified `urchade/gliner_medium-v2.1` @ 40ec419 (pinned in the sidecar
  manifest): entity pass is excellent zero-shot on the 12-type backbone
  (Person 0.99, Organization 0.98, TimeReference 0.94, Technology 0.97 on
  the probe text). REJECTED as the evidence-pass proposer: zero spans for
  every evidence label style and threshold
  (`docs/wiki/experiments/0001-gliner-evidence-pass.md`).
- Shipped the deterministic lexical evidence lane
  (`workers/workers/evidence_proposer.py`): evidence spans are exact
  matches of the rule pack's trigger vocabulary with light lemma
  stripping. Bounded recall by design.
- Candidate generation is evidence-anchored by linear order (subject
  nearest-left, object nearest-right) so asymmetric predicates never emit
  both directions; the compiler's passive inversion applies when the
  optional spaCy parse supplies voice.
- Fixed, found by the live smoke test:
  - chunk FK ordering (parents before children);
  - failure receipts inside an aborted transaction (savepoint +
    rollback + durable failure receipt + StageFailed);
  - outbox retry re-arm (`ON CONFLICT DO UPDATE delivered_at = NULL`);
  - JSONB payloads arrive as dicts (scheduler);
  - `SidecarSettings` field name (pin verification);
  - stage receipt now clears `error` on a successful retry.

## Proof

Live end-to-end run on this Mac (Postgres in Compose, uvicorn API, intake
+ extract workers, gliner-runtime):

- `/intake` replay of the same canonical input returns the same `run_id`
  with `already_exists=true`; one run, one outbox event.
- Clean corpus produced exactly the expected facts, correctly directed,
  no duplicates: has_role(Sarah,Polaris), uses(Polaris,M3 chip),
  part_of(chip,laptop), depends_on(laptop,chip). Active+passive founded
  collapses to one fact id.
- Control census promoted all four runs to `query_ready` with durable
  heartbeats and a Postgres lease.
- 26 unit/determinism/contract tests pass; all three guards green.

## Rejected claims

- GLiNER as the evidence-class proposer (measured, rejected).
- spaCy as a hard dependency: orientation degrades to surface order with
  weak provenance when the parser is absent; the manifest records which
  path a run used.
