# WORK LOG — R4 PROFILE_ATOM retrieval lane

## Contract

FINAL-RETRIEVAL-ROUTING-SYNTHESIS-V1 R4 / §42 / §64: Profile Atom = semantic routing/
expansion. After the R4 substrate (register 11.159) persisted+projected atoms, this wires the
atom lane into retrieval: atoms nominate docs that converge through parent-MAP → children,
kind-selected per intent. Do NOT collapse into the global profile — atoms are their own
search over their own collection, unioned into the shared localization (§42).

Owner: `worker`. Verifier: `test_query_intent.py` (policy) + `chat_regression --check`
(flag-off) + a live contribution probe. Rollback: `atom_kinds` empty (default) / intent
policy off / dualread off — the atom search never runs.

## Changes

- **`candidate_engine.py`:** `CandidateBudget.atom_kinds` (tuple, default ()) + `atom_k`.
- **`query_intent.py`:** `IntentPolicy.atom_kinds` per intent (§33 mechanism/relational atom
  columns); `apply_intent_policy` sets `budget.atom_kinds`.
- **`chat_retrieval.py`:** the `dualread_search` nominator now, when `atom_kinds` is non-empty,
  runs `profile_atom_projection.search_atoms` (kind-filtered) and unions the atom-nominated
  doc_ids into the SAME `search_parent_maps` call (one map search, §17). Optional + guarded —
  an atom-lane failure never breaks routing.

## Proof

- **Unit:** `test_query_intent.py` — `apply_intent_policy` sets atom_kinds per intent (EXACT
  none, MECHANISM the 4 mechanism kinds, EXPLORATORY all 10, RELATIONSHIP includes SEEALSO);
  full determinism suite green.
- **Flag OFF byte-identical:** `chat_regression --check` → `131 rows, 0 failing` (atom_kinds
  empty by default ⇒ no atom search).
- **LIVE (cinema atom collection, 1847 pts):** `search_atoms` returns 8 hits nominating 3–6
  distinct docs per mechanism/relational query — the atom lane is FUNCTIONAL and nominates
  real docs, converging through the map search. On the 6-doc mapped cohort profile nomination
  already covers the whole mapped universe, so atom docs win no extra top-`dualread_map_k`
  slots (resolved parents 24 either way) — correct: atoms compete on relevance and add
  coverage on the FULL corpus as backfill maps more docs.

## Rejected claims

- **Not** collapsed into the global profile (own collection + kind-filtered search, unioned).
- **Not** factual evidence (routing/expansion nomination only).
- **Not** a hard gate / not lossy (additive doc nominations; flag-off byte-identical).

## Open contract gaps

- **GATED — measurable atom uplift** depends on (a) more docs mapped (parent-MAP backfill) so
  profile nomination no longer covers the whole mapped universe, and (b) the richer atom kinds
  (latent_pattern/boundary/tension/… = 0) from vNext profile regeneration. The lane is built +
  additive + safe now; its incremental recall shows on the full corpus.
- **Next:** R6 Resolution-Lift gatherer + bounded probe; then MAP/graph/latent assist, the
  synthesis evidence-role bundle (§44–§47), breadth (§48), and production routing qualification.
