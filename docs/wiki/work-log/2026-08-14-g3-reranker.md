# G3: cross-representation reranking qualification

## Contract

Implement and evaluate cross-representation reranking over the EXISTING
fused retrieval candidates, with a baseline-vs-reranked gate focused
on evidence ranking quality and the pre-authored surface-noise gate
(gate 7f). Production extraction stays frozen; the reranker is a
CANDIDATE (never silently enabled). Stop after the empirical verdict.

## Changes

- `sidecars/reranker/manifest.toml` (new): pinned identity —
  Qwen/Qwen3-Reranker-0.6B @ e61197ed45024b0ed8a2d74b80b4d909f1255473,
  TOFU weights discipline.
- `sidecars/reranker/server.py`: loads the pinned revision; /ready is a
  REAL forward pass; /rerank returns scores + order + model identity.
- `shared/polymath_shared/clients.py`: RerankerClient.
- `shared/polymath_shared/rerank.py` (new): deterministic wrapper —
  reorders the fused document + child lists only (never adds/removes
  candidates → recall cannot drop); attaches rerank_score + model
  id/revision + version provenance; unavailable reranker is LOUD
  (RerankUnavailable → 502 in the endpoints).
- `shared/polymath_shared/settings.py`: `sidecars.g3_reranker`
  (POLYMATH_G3_RERANKER, default off — matches the gate 7f env name).
- /retrieve, /evidence, /chat: rerank the fused candidates when the
  candidate flag is on; per-lane ablations untouched.
- Tests: `tests/determinism/test_rerank_wrapper.py` (5, no stores).

## Proof

- Gate 7f empirical (live G2 fixtures, reranker sidecar with a real
  forward pass):
  BASELINE (off): surface-noise ranked #2 of the fused documents —
  the pre-authored gate fails without reranking.
  RERANKED (on): complementary trio retained in the top 3,
  surface-noise pushed to #4 (out of top-3), candidate set unchanged.
  Determinism: two runs identical in document order, rerank scores,
  and child order.
- Full suites green (165 unit + 20 integration, default config
  unchanged; G1 golden trace untouched when the candidate is off).

## Rejected claims

- No calibrated weights invented (ordinal application only).
- No extraction change; no recall gate (candidates never dropped).
- Not promoted to a production default — verdict only, per the G3
  brief.

## Open contract gaps

- Promotion of reranking to a default (or its role in G5 evidence
  assembly) remains a product decision after G4 scale evidence.
