# Phase G2: frozen G1, embedding contracts, dense lane, receipt-supersede fix

## Contract

Freeze G1 as a behavioral golden test; give the neural layer a frozen
representation contract it must obey; split child dense vs child lexical
lanes with per-hit representation provenance; fix the receipt semantics
so verification supersedes claims without erasing attempt history.

## Changes

- G1 golden trace frozen: the cross-domain fixture asserts the exact
  order Loop Engineering (0), Predicate Compiler (1), Prompt Graph (2)
  with filler excluded; the adversarial G2 fixture lives in a separate
  corpus namespace so it cannot perturb the frozen fixture.
- `shared/embedding_contracts.py`: the frozen contract — contract id is
  the content hash of (version, model, revision, dimension, distance,
  normalization, prefixes, tokenization, token/batch limits,
  representation_kinds). Any field change = a NEW contract id (gate 4).
  No backend/device field (gate 5). `representation_kind` distinguishes
  document_profile / parent_summary / child_chunk / query. hash-embed-v1
  is retained permanently as the zero-model test contract. Neural
  contract pins Qwen/Qwen3-Embedding-0.6B @ 97b0c614be4d.
- Sidecar: embedder implemented for real (sentence-transformers, pinned
  revision, TOFU weights verification, /ready runs a real forward pass,
  /infer returns the contract id with every batch).
- Projector resolves the ACTIVE contract from settings; the neural
  contract embeds through the sidecar, hash-embed stays local. Index
  names carry the derived contract id — a contract bump is a new index
  version, never a mutation (gate 4).
- Four independent lanes in /retrieve: document, parent, child dense,
  child lexical — reported pre-fusion with representation_kind,
  contract_id, raw rank/score (gates 2, 3). Fusion is rank-based RRF
  only (gate 6). Dense rows without a vector score cannot pollute
  fusion.
- Receipt semantics fixed: migration 0004 adds append-only
  `projection_attempts` + an `active` claim flag on projection_receipts.
  VERIFY supersedes claims (active=false) — it never erases the
  historical commit trail; the census reads active claims only and
  re-projection re-claims.
- G4 policy test: graph expansion is monotonic (additive only).
- Qdrant moved to host port 6334 — the user's live v3.3 stack on 6333
  was discovered mid-session and is never touched; leaked test
  collections on 6333 were removed. qdrant-client pinned to 1.13.x to
  match the server.

## Proof

- 40 unit tests + 14 integration tests + 3 guards green.
- Live neural proof: the conceptual query "How should machines turn
  words into structured knowledge?" — zero shared vocabulary — routes
  Prompt Graph (0.42), Predicate Compiler (0.40), Loop Engineering
  (0.37) via the dense lane while the lexical lanes find nothing (gate
  7e, integration test under POLYMATH_NEURAL_EMBEDDER=1).
- Gates 7a (terminology absent), 7b (child conflicts with document
  routing — child survives, document lane stays clean), 7c (dual
  domain) pass on the adversarial fixture.
- Contract unit gates: revision/dimension/preprocessing/normalization
  changes each yield a new contract id; no backend field exists;
  hash-embed is permanent and byte-stable.

## Rejected claims

- Gate 7f (surface-vocabulary noise) is NOT claimed at G2: it needs
  cross-representation discrimination over FUSED candidates — that is
  the G3 reranker's job. The test is admitted with a G3 gate.
- No score-normalization coefficients anywhere: fusion stays rank-based.

## Open contract gaps

- G3 reranker (union candidates, fixed budget, pre/post rank trace);
  G4 graph-expansion policy tests at scale; G5 evidence assembly.
- Record the embedder weights digest in the manifest after the first
  production deploy and set POLYMATH_REQUIRE_PINNED=1.
