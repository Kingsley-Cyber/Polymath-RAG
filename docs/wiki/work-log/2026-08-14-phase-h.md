# Phase H: lexical-semantic waterfall qualification

## Contract

Run the frozen evaluation corpus through two arms — lexical baseline
(`load_rule_pack(use_resources=False)` + `candidates(enrich=False)`)
vs lexical-semantic hybrid (`use_resources=True` + `enrich=True`) —
over identical frozen upstream artifacts, score against frozen gold,
produce the waterfall/cohorts/predicate/transition artifacts, and
return a verdict based on Δ-correct / Δ-incorrect, not aesthetics.

## Changes

- `load_rule_pack(use_resources=False)`: the clean arm boundary — same
  compiler DAG, manual YAML triggers only, empty lexical tables, no
  resource contract. The hybrid arm is the existing production path.
- `build_candidates(enrich=False)`: baseline candidates carry zero
  resource-derived evidence.
- `eval/phase_h/harness.py`: deterministic two-arm evaluation over the
  frozen corpus (gold entities/evidence/scope = frozen upstream
  artifacts — input parity by construction, no GLiNER variance).
  Emits the full artifact set: frozen inputs, gold, both arms'
  predictions + sha256, waterfalls, metrics, paired transitions,
  predicate breakdown, resource cohorts, assertion breakdown, polysemy
  breakdown, coverage report, changed examples.
- `eval/phase_h/REPORT.md`: the evidence package with the verdict.
- Harness tests: arm isolation, input parity, gold immutability,
  deterministic evaluation, transition accounting, metric
  reconciliation, provenance requirements, direct/composed
  distinction.

## Proof

- Determinism: baseline predictions sha256 0afdd1a4… and hybrid
  aed28607… identical across two runs each.
- 71 unit + 12 integration + 3 guards green.
- Verdict: NO MATERIAL BENEFIT — Δcorrect=0, Δincorrect=0, Δmissed=0
  on 33 units (29 correct, 2 spurious edges, 2 misses in BOTH arms).
- Isolation proven real: class-member trigger `coin` compiles
  UNSUPPORTED in the baseline, FOUNDED/CREATED in the hybrid.
- Three harness-only defects found and fixed per the bug protocol
  (substring offset misassignment, attributed-qualifier scoring,
  spurious-edge accounting), both arms rerun, regression tests added.
  Production code untouched.

## Rejected claims

- No claim that the layer improves extraction: the frozen corpus is
  structurally blind to the boundary (every gold trigger was authored
  from the manual vocabulary; no resource-expanded or multi-sense
  examples). The verdict stands as measured.
- No corpus modification to produce a favorable delta; no threshold
  tuning; no fuzzy SemLink joins.

## Open contract gaps

- Corpus v1.1 must add resource-expanded-trigger examples and
  multi-sense disambiguation items before the hybrid/default question
  can be decided. The `coin` probe shows the class-breadth risk
  (FOUNDED sense) that needs measuring.
- W2 (b11 ARG1→ARG2 pairing) and W7 (a02 passive orientation) remain
  the dominant measured losses — upstream of the resource boundary.
