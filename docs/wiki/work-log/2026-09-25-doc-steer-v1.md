# DOC-STEER-V1: the document level steers the search, per mode

## Contract
- The owner, 2026-09-24 (gap D-10): "the overall document level can be used as a steering search association based on
  query, so its not detemrinsitic in a bda way", with WILDCARD emphasising "theory, concept on top of how it does things".
- The replay (register 11.477, `2026-09-24-doc-steer-replay.md`) and the agent's recommendation: GRAPH bridges + anchors;
  WILDCARD theories, concepts, latent patterns and tensions, never inversions; HYBRID keeps the SEE ALSO blend alone; the
  question weight stays 0.7.
- The owner, 2026-09-25: "build it" and "i agree".

## Changes
- `shared/polymath_shared/skeleton_routes.py`: `DOC_STEER_FLAG = POLYMATH_CHAT_DOC_STEER` and the per-mode table
  `DOC_STEER_KINDS` (GRAPH `BRIDGE`, `ANCHOR`; WILDCARD `THEORY`, `CONCEPT`, `LATENT_PATTERN`, `TENSION`). The routes set
  `doc_steer_kinds` only when both this flag and the SEE ALSO blend flag are on. HYBRID, FAST and GNN get none.
- `shared/polymath_shared/candidate_engine.py`: `CandidateBudget.doc_steer_kinds` (default empty = off) and
  `doc_steer_items` (4).
  - Lane G's cap grows by `doc_steer_items × seealso_blend_children` when the steer is on.
  - The receipt, with the steer on, names each blended line with its `kind` and adds `steer_kinds` + `steer_candidates`.
  - With the steer off, the receipt keeps its old shape.
- `shared/polymath_shared/seealso_blend.py`: each blended row carries its line's kind (`seealso_blend.kind`; `SEEALSO` when
  the line has none).
- `orchestrator/orchestrator/api/chat_retrieval.py`, `fanout_search`: after the SEE ALSO lines of the question's
  documents, the same documents' lines of the mode's kinds are fetched (ranked by the question, `doc_steer_items`),
  deduplicated by text and blended the same way. Knob: `POLYMATH_CHAT_DOC_STEER_ITEMS`.
- Tests:
  - `test_seealso_blend.py`: 2 new (the per-mode kinds, both flags, never INVERSION; each row carries its kind); the tag
    pin gains `kind`;
  - `test_candidate_engine.py`: 1 new (the steer rows get room in lane G; the receipt names the kinds);
  - `tests/contracts/test_search_atoms_callers_scoped.py`: 5 corpus-scoped calls, 2 document-filtered (the blend and the
    steer both read only the question's documents).
- Replay: `docs/wiki/experiments/doc-steer-2026-09-24/replay.py` gains the `built` config (the production flag, no replay
  wrapper) → `replay_built.json`.

## Rejected claims
- "Steer HYBRID with concept lines": no change in 2 of 2 replay runs, for +0.5–0.8 s of lane time (11.477).
- "Use every WILDCARD kind": INVERSION lines search for the question's opposite; they cost on-point passages (11.477).
- "Let the steer run without the blend": the replay proved the pair; the steer shares the blend's documents, weight and
  lane cap, so it rides the blend's flag.
