## Contract

- **Smallest acceptance:** each screen renders REAL backend data; the readiness triad stays three distinct
  concepts; the dormant backlog is shown as dormant, not as live failure.
- **Owner / public contract:** none changed.
- **Verifier / rollback:** `npm run build` + live browser verification; rollback = revert.

## Changes

- **F4 `EvidenceInspector.tsx`** — per row: document · section/parent · child · exact text (expandable) ·
  rerank score · provenance · citation tag. Rows that reached the FINAL selection are separated from
  candidates that did not. Rows whose provenance is entirely summary/card lanes are tagged **ROUTING**,
  enforcing plan §4: Profiles, Atoms and pMAP explain why a source was FOUND and are never factual evidence.
- **F5 `QueryTrace.tsx`** — requested vs executed mode (drift highlighted), classified intent (labelled inert
  because INTENT_POLICY is OFF), retrieval version, latency, degradation, the lane table, and the compiler plan.
- **F8 `Files.tsx`** — the triad plus per-document vNext with the backend's own counts (parents, children,
  pMAP eligible/mapped/excluded/unresolved, profile tier, graph entities/relations). Unresolved > 0 renders red.
- **F10 `ControlPlane.tsx`** — four function cards; `limiter_refused` (LOCAL, 0 HTTP) kept visually distinct
  from `http_429` (a real spent request); `parent_enrichment` named a legacy stage pin, not a fifth pool;
  account ENV NAMES only in the lane drill-down.
- **F9 `Graph.tsx`** — predicate distribution, and an explicit statement of what is NOT served.
- `lib/api.ts` gains `predicates` and `capabilities` so no screen fetches directly.

## Rejected claims

- **"Clear the 282 stalls so the badge goes green."** REJECTED — owner-forbidden, and it would destroy the
  evidence the backlog classification rests on. The UI explains the reason instead.
- **"Show `processing` as live activity."** REJECTED while GAP-4 stands; `processingIsTrustworthy()` returns
  false and the number carries its caveat.
- **"Build an entity browser for F9."** REJECTED — there is NO graph route in the API (GAP-7). Rendering an
  entity graph the backend cannot attest would be the exact opposite of "only source-attested relationships may
  appear as canonical truth". The screen shows what exists and names what does not.
- **"Treat every evidence row as grounding."** REJECTED — routing-lane rows are tagged ROUTING.
