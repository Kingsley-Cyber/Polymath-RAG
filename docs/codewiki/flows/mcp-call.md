# flow: mcp-call

An MCP tool call to Server A (HTTP :8930): the key check (principals), scope, the tool, the call into the orchestrator, the answer. Every tool is a thin, trimmed call to the orchestrator API on `http://127.0.0.1:7200`, so MCP can never bypass the pipeline's own gates — `orchestrator/orchestrator/mcp_server.py:5-9` [DERIVED].

## failure modes

1. Every `/mcp` call answers 503 -> no `POLYMATH_MCP_API_KEY` configured (FAIL-CLOSED V2; the V1 process had booted without the key and the public mirror answered anyone) -> look at `orchestrator/orchestrator/mcp_server.py:38-40`, `:77` [DERIVED]
2. 401 -> unknown/revoked bearer key, OR a tool call with no authenticated principal (`NO_PRINCIPAL: this call carries no authenticated principal (fail closed)` — the gate never ran, e.g. lost context) -> `orchestrator/orchestrator/mcp_server.py:37` [DERIVED], `:142` [DERIVED], `:150-152` [DERIVED]; `orchestrator/orchestrator/mcp_principals.py:5-7` [DERIVED]
3. 403 -> scope not granted (DEFAULT DENY: only the actions in scopes, on only the corpora/adapters it lists; a tool with no policy is admin-only), or remote/non-admin `upload_document` (`REMOTE_PATH_UPLOAD_DISABLED`) -> `orchestrator/orchestrator/mcp_principals.py:9-10` [DERIVED], `:78` [DERIVED]; `orchestrator/orchestrator/mcp_server.py:101-104` [DERIVED], `:255-257` [DERIVED]
4. 429 -> principal over its optional requests-per-minute -> `orchestrator/orchestrator/mcp_server.py:37` [DERIVED], `:114` [DERIVED]; `orchestrator/orchestrator/mcp_principals.py:8` [DERIVED]
5. Transport rejection -> Host/Origin outside `allowed_hosts`/`allowed_origins` (DNS-rebinding allowlist) -> `orchestrator/orchestrator/mcp_server.py:81-92` [DERIVED]
6. Upload 409 `CROSS_CORPUS_CONTENT_COLLISION` -> the content already lives in ANOTHER corpus (content belongs to one corpus) -> `orchestrator/orchestrator/mcp_server.py:253-254` [DERIVED]
7. Silent fallback: deprecated tools (`retrieve`, `retrieve_evidence`, `compile_plan`, `ask`) remain callable but never listed, and `polymath_search` "used to reach the frozen LEGACY route through them" -> `orchestrator/orchestrator/mcp_server.py:32-33` [DERIVED], `:123-128` [DERIVED]
