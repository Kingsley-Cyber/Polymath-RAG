# Polymath Migration Bootstrap Bundle

Copy these files into:

`~/Documents/polymath-rebuild/polymath-v4/docs/migration/`

The three controlling documents are:

- `MIGRATION_POLICY.md`
- `BOOTSTRAP_CONTEXT.md`
- `EXECUTION_PLAN.md`

The coding agent owns and maintains the operational documents:

- `CAPABILITY_MAP.md`
- `AUTO_DECISIONS.md`
- `PARITY_MATRIX.md`
- `CONTINUATION.md`
- `ADR-TRAIL-EMBEDDING.md`
- `FINAL_MIGRATION_REPORT.md`

Use `NEW_SESSION_BOOTSTRAP_PROMPT.md` as the first prompt in the fresh execution session.

The controlling documents should not have their mission, ownership model, invariants, or acceptance criteria silently rewritten during ordinary implementation.
